# Python 学习之路 (Python Learning Journey)

这是我的 Python 学习代码仓库，记录了我从零基础开始的打怪升级之路。

## 🛠️ 运行环境
- Python 3.x
- 核心依赖：`requests` (用于网络请求)

## 📂 项目目录 (持续更新中)
- `day8_word_count.py`：单词统计小脚本
- `day12_func_args.py`：函数高级参数练习
- `day16_requests.py`：使用 requests 库调用百度接口
- `day17_oop_student.py`：面向对象基础练习
- `day19_oop_contacts.py`：JSON 版通讯录系统 (OOP重构)
- `day21_oop_todo.py`：命令行待办事项系统 (带数据持久化)

## 🚀 如何运行
1. 克隆代码到本地
2. 安装依赖：`pip install requests`
3. 运行任意脚本，例如：`python day21_oop_todo.py`

## 📝 学习心得
- 掌握了 Python 基础语法与数据结构
- 理解了面向对象编程（类、继承、多态）
- 学会了文件读写（JSON/CSV）以及模块化开发
